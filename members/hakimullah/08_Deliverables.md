# Deliverables

## Required Deliverables

### 1. PRD
**Product Requirements Document**

Defines what product we are going to build.

### 2. BRD
**Business Requirements Document**

Defines why the business needs the platform.

### 3. Functional Requirements
Defines what the software must be able to do.

### 4. MVP Feature List
Defines what is included in the first release and what is intentionally left for later.

Requirements baseline for MVP planning.
