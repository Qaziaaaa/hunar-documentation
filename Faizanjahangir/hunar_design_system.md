# HUNAR Design System Reference

> The core colors, button styles, and usage rules based on the HUNAR design identity.

## 🎨 1. Color Palette
The primary color system behind the whole UI.

*   **Navy:** `#123B5D`
*   **Teal:** `#0F8B8D`
*   **Orange:** `#F59E0B`
*   **Background:** `#F8FAFC`
*   **White:** `#FFFFFF`
*   **Dark:** `#172033`
*   **Gray:** `#64748B`
*   **Success:** `#16A34A`
*   **Error:** `#DC2626`

---

## 🔘 2. Buttons & Interactions

### Action Buttons
*Teal = action & trust. Every main CTA (Call to Action) in HUNAR uses this.*
*   **Color Used:** Solid Teal (`#0F8B8D`)
*   **Examples:** `+ Post a Job`, `✓ Accept Offer`, `Approve Repair`, `Pay Rs. 0`

### Secondary & Outline Buttons
*White + navy border = calm, trust-based options.*
*   **Color Used:** White background with Navy (`#123B5D`) border and text.
*   **Examples:** `Become a Worker`, `View All`
*   **Other Styles:** Ghost buttons / Navigation links (text only, no background).

---

## 🏷️ 3. Status & Semantic Colors
*Orange draws the eye, green means done, red is a problem.*

*   **Pending / Attention (Orange):** Used for tags like `Pending offer` and `Offer highlight`.
*   **Verified (Teal):** Used for `Verified` badges.
*   **Completed (Green):** Used for `Completed` status tags.
*   **Problem / Danger (Red):** Used for negative actions like `Cancelled`, `Reject`, or `Cancel Job`.

---

## 📖 4. Quick Rules (Usage Guidelines)
*The whole identity in one line.*

*   **Navy (`#123B5D`) = Trust** → Used for logo, headings, numbers, prices.
*   **Teal (`#0F8B8D`) = Action** → Used for buttons, accept, pay, verified.
*   **Orange (`#F59E0B`) = Attention** → Used for ratings, offers, pending.
*   **Green (`#16A34A`) = Success** → Used for completed, approved, online.
*   **Red (`#DC2626`) = Problem** → Used for errors, cancelled, rejected.
